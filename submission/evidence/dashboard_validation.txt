# Dashboard — kết quả validator và số đo thật

================================================================================
1. KẾT QUẢ VALIDATOR
================================================================================

  $ python scripts/validate_dashboard.py
  HỢP LỆ: 6/6 panel có trong dashboard contract.

  exit code 0

Validator kiểm tra CẤU TRÚC contract config/dashboard.yaml: đúng 6 panel với ID
{latency, traffic, errors, cost, tokens, quality}, mỗi panel đủ 8 field bắt buộc,
threshold.aggregation phải thuộc aggregations của chính panel đó, operator chỉ
nhận lte/gte, time_range_minutes = 60, refresh_seconds trong khoảng 15-30.

Nó KHÔNG chứng minh biểu đồ trong ảnh dùng đúng dữ liệu — evidence runtime vẫn
bắt buộc (xem mục 4).

================================================================================
2. SÁU PANEL VÀ SỐ ĐO THẬT
================================================================================

Nguồn dữ liệu: data/logs.jsonl
Cửa sổ đo: 10 request baseline lúc 2026-08-11T05:54:41-43 UTC
           (python scripts/load_test.py --concurrency 5, incident OFF)

  panel    | đơn vị      | threshold          | ĐO ĐƯỢC                | kết luận
  ---------|-------------|--------------------|------------------------|----------
  latency  | ms          | p95 <= 3000        | p50 150, p95 896,      | PASS
           |             |                    | p99 896, min 150       |
  traffic  | req/phút    | rate >= 1          | 10 request trong ~2.3s | PASS
  errors   | percent     | error_rate <= 2    | 0.00 (0/10),           | PASS
           |             |                    | error_breakdown rỗng   |
  cost     | usd         | total <= 2.5       | 0.020595               | PASS
  tokens   | token       | sum <= 50000       | in 330, out 1307,      | PASS
           |             |                    | out p95 178            |
  quality  | score 0-1   | mean >= 0.75       | 0.88                   | PASS

Vì sao p95 = 896ms trong khi p50 chỉ 150ms:
  Request đầu tiên sau khi process khởi động phải fetch prompt từ Langfuse
  (cache_ttl_seconds=60 còn rỗng). Từ request thứ hai trở đi latency về đúng
  150ms. Đây là lý do alert HighLatencyP95 đặt for=5m và min_sample=10 — bắn
  ngay lập tức thì mỗi lần deploy sẽ tạo một báo động giả.

================================================================================
4. HẠNG MỤC CÒN THIẾU — DASHBOARD RUNTIME
================================================================================

CHƯA CÓ ảnh dashboard runtime. Contract đã hợp lệ và số liệu đã có, nhưng nhóm
chưa dựng dashboard trên công cụ nào nên chưa chụp được ảnh thể hiện tên panel,
time range 60 phút, đơn vị và threshold line như docs/dashboard-spec.md yêu cầu.

Việc còn phải làm:
  1. Dựng 6 panel từ data/logs.jsonl bằng Streamlit / notebook / Grafana
     (docs/DASHBOARD_SETUP.md), giữ đúng tên panel, đơn vị và threshold của
     config/dashboard.yaml.
  2. Chụp ảnh trạng thái bình thường  -> dashboard_before.png
  3. python scripts/inject_incident.py --scenario rag_slow
     chạy lại load test, chụp ảnh  -> dashboard_after.png
     (panel latency phải nhảy rõ, các panel còn lại giữ nguyên)
  4. python scripts/inject_incident.py --scenario rag_slow --disable

Ảnh phải nhìn được: tên panel, time range, đơn vị, threshold/SLO line.

================================================================================
5. SLO ĐANG ÁP DỤNG
================================================================================

Nguồn: config/slo.yaml (8 SLI đang bật + 2 planned_slis chưa bật)

  SLI                       | objective | target | nhóm
  --------------------------|-----------|--------|------------------
  latency_p95_ms            | 3000 ms   | 99.5%  | hạ tầng
  error_rate_pct            | 2 %       | 99.0%  | hạ tầng
  daily_cost_usd            | 2.5 USD   | 100%   | hạ tầng
  traffic_rate_per_minute   | 1 req/min | 99.0%  | hạ tầng (sàn liveness)
  quality_score_avg         | 0.75      | 95.0%  | LLM/agent
  cost_per_request_usd      | 0.006 USD | 99.0%  | LLM/agent
  output_tokens_p95         | 400 token | 99.0%  | LLM/agent
  pii_in_output_count       | 0         | 100%   | LLM/agent (tuân thủ)

Ngưỡng đặt theo quy tắc objective ~ 2x p95 quan sát được. Baseline đo thật:
cost_usd p95 = 0.0027, tokens_out p95 = 173, quality mean = 0.87.

Chưa bật, ghi ở planned_slis kèm blocked_on:
  prompt_fallback_rate_pct      cần ghi prompt_source vào log
  retrieval_grounding_rate_pct  cần cờ retrieval-miss riêng (doc_count luôn >= 1
                                kể cả khi miss, app/mock_rag.py:23)

Alert rules: config/alert_rules.yaml (8 alert symptom-based)
Runbook    : docs/alerts.md (8 mục, mỗi mục 3 bước kiểm tra đầu tiên)
