## Các bước còn lại cần thực hiện thủ công

### Bước 1: Tạo Prompt Versions trên Langfuse
```bash
python scripts/role2_setup.py
```

### Bước 2: Chụp ảnh Langfuse UI
1. **trace_v1.png** - Trace có prompt_version=1
2. **trace_v2.png** - Trace có prompt_version=2
3. **label_promotion.png** - Ảnh đổi label production sang v2
4. **label_rollback.png** - Ảnh rollback về v1

### Bước 3: Chạy Challenge (sau khi Lab Coach release)
```bash
python scripts/inject_incident.py
python scripts/load_test.py --challenge --concurrency 5
```

### Bước 4: Hoàn thiện REPORT.md
Điền đầy đủ thông tin trong `submission/REPORT.md`:
- Thông tin nhóm
- Kết quả kỹ thuật
- Trace IDs từ Langfuse
- Challenge investigation
